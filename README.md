## v1 — Управление клиентами и каталогом товаров

В рамках данной итерации внедрена функциональность работы с учетными записями пользователей, а также расширен API каталога возможностью точечного поиска товара по идентификатору.

### Модуль пользователей

- Регистрация нового пользователя (сохранение связки имени и адреса электронной почты).
- Поиск конкретного профиля по email.
- Выгрузка полного перечня зарегистрированных пользователей.
- Входная валидация обязательных атрибутов при создании записи.
- Контроль корректности почтового формата при фильтрации по email.

### Каталог товаров

Поддержан полный жизненный цикл позиций: создание, модификация, удаление и получение всего списка[cite: 15]. Реализован дополнительный эндпоинт для выборки конкретного товара по первичному ключу (`ID`).

### Технический стек и особенности

- Сетевой слой на базе стандартного пакета `net/http` и роутера `chi`.
- Взаимодействие с PostgreSQL через драйвер и пул соединений `pgx`.
- Сквозная передача `context.Context` из входящих HTTP-запросов в слой хранилища для контроля таймаутов и отмены.
- Структурированное логирование событий приложения посредством библиотеки `slog`.
- Покрытие HTTP-хэндлеров юнит-тестами с использованием собственных mock-реализаций репозитория.

### Развертывание и локальный запуск

1. Синхронизация и загрузка модулей Go:
   ```bash
   go mod tidy
   ```

2. Инициализация переменных окружения из шаблона:
   ```bash
   cp .env.example .env
   ```

3. Поднятие инфраструктурных сервисов (PostgreSQL) в Docker:
   ```bash
   docker compose up --build
   ```

4. Статический анализ кодовой базы[cite: 15]:
   ```bash
   golangci-lint run ./...
   ```
