# Pet Shop Backend Service

Серверная часть интернет-магазина зоотоваров на Go[cite: 11]. Проект служит демонстрацией практической работы с PostgreSQL: от проектирования схемы и реляционных связей (`JOIN`) до управления строгими транзакциями, блокировками данных и составления аналитических SQL-выборок[cite: 11].

---

## Архитектурный подход и структура каталогов

Кодовая база спроектирована по канонам многослойной чистой архитектуры (Clean Architecture) с изолированными зонами ответственности[cite: 11]:

- `cmd/` — исполняемые файлы проекта[cite: 11]:
  - `app/main.go` — сборка зависимостей (DI-контейнер), чтение конфигурации, подключение пула соединений к базе и старт HTTP-сервера[cite: 11].
  - `migrator/main.go` — CLI-утилита для наката и отката миграций схемы данных (`golang-migrate`)[cite: 11].
- `config/local.yaml` — параметры окружения для локальной разработки[cite: 11].
- `internal/` — закрытый бизнес-код приложения[cite: 11]:
  - `config/` — загрузка и строгая типизация переменных конфигурации[cite: 11].
  - `handlers/` — сетевой уровень (HTTP-контроллеры, маппинг DTO, парсинг тела запроса и сериализация JSON-ответов)[cite: 11].
  - `storage/` — слой персистентности: абстрактные интерфейсы репозиториев и их конкретная реализация под PostgreSQL[cite: 11].
  - `models/` — доменные сущности и структуры предметной области[cite: 11].
  - `lib/` — общие вспомогательные пакеты (структурированное логирование на базе стандартного `slog`)[cite: 11].
- `migrations/` — версионированные SQL-скрипты миграций (`up` / `down`)[cite: 11].
- `Taskfile.yaml` — набор шорткатов для автоматизации рутины (запуск линтера, миграции)[cite: 11].

## Итеративный план разработки по веткам

Каждая ветка поэтапно наращивает функциональность сервиса[cite: 11]:

- **`main`** — каркас сервиса: точка входа, инициализация зависимостей, подключение к PostgreSQL и эндпоинт проверки работоспособности (`health-check`)[cite: 11].
- **`v1` — Каталог и клиентская база:**
  - Базовые сущности `users` и `products`, простые операции выборки и вставки (`SELECT`, `INSERT`)[cite: 11].
  - REST-эндпоинты для управления товарами и клиентами[cite: 11].
- **`v2` — Механика заказов:**
  - Модели `orders` и составные элементы `order_items`[cite: 11].
  - Оформление заказа, сквозная выборка позиций с помощью связей `JOIN`[cite: 11].
- **`v3` — Процессинг чекаута и транзакции:**
  - Реализация сценария `PlaceOrder` в рамках единой транзакции (`tx`)[cite: 11].
  - Контроль и списание остатков на складе (`stock`), создание заказа и фиксация платежа в таблице `transactions` с гарантией `Commit` / `Rollback`[cite: 11].
  - Эндпоинт оформления корзины `POST /checkout`[cite: 11].
- **`v4` — Аналитический слой и отчеты:**
  - Полная сводка покупок и финансовых операций через цепочки `JOIN`[cite: 11].
  - Агрегационные SQL-запросы (`GROUP BY`) для выдачи топа популярных позиций `GET /products/popular`[cite: 11].
